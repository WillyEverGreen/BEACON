# Detailed CLI Audit Runner

Use `scripts/run_detailed_audit_cli.py` to audit any URL with any scan mode and export a complete report bundle.

## What It Exports

Each run creates one timestamped folder inside `tests/artifacts/cli_audits/` (or your custom `--output-dir`) containing:

- `audit_result.raw.json`: full raw `run_audit` payload (all pipeline fields)
- `audit_analysis.json`: derived summaries (severity, dedup, WCAG, groups, pipeline snapshot)
- `audit_report.engine.md`: markdown report generated by the core engine
- `audit_report.cli.md`: operator-friendly markdown report with top issues and snippets
- `issues.full.json`: full issues array
- `issues_flat.csv`: flattened issues sheet for manual triage
- `issue_groups.json`: grouped issue payload
- `priority_ranking.json`: top priority ranking payload

The CLI now reports three score views:

- **Calibrated score**: default engine score (confidence-aware; low-confidence findings may be excluded)
- **Strict score**: recomputed with all reported findings contributing to penalties
- **Recommended operator score**: conservative minimum of calibrated and strict scores

## Quick Start

```bash
python scripts/run_detailed_audit_cli.py https://example.com --scan-mode fast
```

## Useful Commands

```bash
python scripts/run_detailed_audit_cli.py https://www.nytimes.com --scan-mode deep --precision-profile balanced --show-top 30
python scripts/run_detailed_audit_cli.py https://www.wikipedia.org --scan-mode max --enable-enrichment --await-enrichment
python scripts/run_detailed_audit_cli.py https://www.etsy.com --scan-mode deep --fail-on-degraded
python scripts/run_detailed_audit_cli.py https://github.com --scan-mode max --min-confidence 0.75
```

## Main Flags

- `--scan-mode {minimal,fast,deep,max}`
- `--precision-profile <name>`
- `--enable-enrichment`
- `--await-enrichment`
- `--max-enrich-issues <int>`
- `--disable-cognitive`
- `--use-cache`
- `--output-dir <folder>`
- `--show-top <int>`
- `--fail-on-degraded`
- `--min-confidence <float>`

## Notes

- This CLI does not hide any core audit fields: use `audit_result.raw.json` for full fidelity.
- Dedup visibility is included through quality gates (`before/after dedup`, removed count, duplicate rate).
- WCAG mapping and issue group summaries are exported in `audit_analysis.json` and `audit_report.cli.md`.
